# Support

- **Questions and usage help:** open a GitHub Discussion (when enabled) or an
  issue using the bug or feature template. Start with the
  [documentation](https://vaheed.github.io/CDNFoundry/) and its
  [troubleshooting](docs/troubleshooting/index.md) section.
- **Bugs:** open an issue with the exact version (`VERSION`), topology, sanitized
  logs and reproduction steps.
- **Security vulnerabilities:** do not open a public issue; follow
  [SECURITY.md](SECURITY.md).

Supported: the latest 1.2.x release, deployed from scratch as documented. This
is community, best-effort support with no SLA. Never post secrets, customer
data, tokens or private keys.
