# Project layout

::: info Source and derived state have different owners
PostgreSQL and source configuration are the durable inputs. PowerDNS rows, edge
snapshots, generated artifacts, built docs, and aggregates are derived. They must
stay rebuildable and never become a hidden source of truth.
:::

Use this table to find the right directory before you search the tree. The
`cdnf-codebase-map` skill goes deeper.

| Path | Purpose |
| --- | --- |
| `core/` | Laravel modular monolith and Filament panels |
| `core/app/Http/Controllers` | Account, domain, administrator, edge, health, metrics APIs |
| `core/app/Filament` | Administrator and domain-user pages/resources |
| `core/app/Jobs` | Bounded asynchronous side effects and global reconciliation |
| `core/app/Models` | Desired and operational Eloquent state |
| `core/app/Support` | External boundaries and reusable typed policy |
| `core/database/schema` | Squashed PostgreSQL and SQLite baseline, loaded on an empty database |
| `core/database/migrations` | Control PostgreSQL migrations added after the baseline |
| `core/routes` | API, web/edge, and scheduler definitions |
| `edge-agent/` | Go enrollment, sync, activation, heartbeat, and task agent |
| `edge-gateway/` | Go edge gateway |
| `docker/openresty/` | Data-driven request/runtime Lua |
| `docker/nginx/` | Web, edge-control, OpenResty, proxy, cache, and fixtures |
| `docker/pdns`, `docker/dnsdist` | Authoritative DNS configuration mounted into upstream images |
| `docker/postgres` | PowerDNS base schema and separate runtime migrations |
| `docker/vector`, `docker/clickhouse` | Telemetry pipeline and schema |
| `docker/prometheus`, `docker/alertmanager` | Metrics and alert configuration mounted into upstream images |
| `compose.dev.yml` | Persistent full development topology |
| `compose.prod.yml` | Role-based production service definitions |
| `deploy/production/` | Fleet examples and production deployment assets |
| `scripts/` | The Fleet tool (`cdnfoundry_fleet`), PKI and environment helpers, and CI checks in `scripts/ci/` |
| `tests/e2e/` | Agent-owned non-UI real-runtime qualification |
| `tests/browser/` | Playwright browser, visual, and accessibility suite |
| `tests/fleet/` | Fleet tool tests |
| `tests/docs/` | Documentation validation: links, design tokens, built site, and `test` blocks |
| `docs/public/screenshots/` | Documentation screenshots generated by the browser suite; never edited by hand |
| `.github/` | Issue forms and CI/publish workflow |
| `.agents/skills/` | Repository execution guides governed by `AGENTS.md` |
| `docs/` | VitePress Markdown source and machine-generated API artifact |

## Module rule

The control plane is one Laravel application. Normal CRUD uses controllers, form
requests, policies, Eloquent models, resources, and Filament resources. Jobs own
asynchronous effects. Support classes exist only for a real external boundary or
a typed reusable policy. Do not add repository or manager wrappers around ordinary
CRUD.

Production names describe behaviour and must not include roadmap phase numbers,
`V2`, `New`, or `Final`.
