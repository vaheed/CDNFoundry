# Roadmap

**Status: finished.** The staged delivery roadmap that guided CDNFoundry
through its 0.x releases is complete. Everything it planned is delivered in
[v1.2.1](operations/releases/v1.2.1.md), which is a zero-state release: deploy
it from scratch, there is no upgrade path from earlier versions.

The delivered scope is described by the product documentation: the
[architecture](architecture/index.md), [guides](guides/index.md) and
[reference](reference/index.md). The owner-run browser checklist for the
delivered screens is maintained in the repository as
`docs/manual-browser-qualification.md`.

What v1.2.1 has and has not been qualified for is stated in the
[release notes](operations/releases/v1.2.1.md#support-statement).

The complete text of the finished plan is archived, unmodified apart from a
status banner, at
[`docs/legacy/staged-delivery-roadmap.md`](https://github.com/vaheed/CDNFoundry/blob/dev/docs/legacy/staged-delivery-roadmap.md).
It is historical and is no longer maintained.

New work is accepted as separate, bounded changes through the
[contribution process](contributing/index.md) and must keep the invariants in
`AGENTS.md`.
