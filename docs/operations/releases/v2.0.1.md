# CDNFoundry v2.0.1

v2.0.1 makes Fleet easier to run. It does not change the control plane, DNS, or the
edge runtime, and you can upgrade from v2.0.0 with Fleet.

## What changed

- **No keys or manifests to paste.** Fleet takes the release you chose at setup (or,
  for an upgrade, the tag your checkout is on), looks up the published image digests, and signs the release with a key it keeps in
  the encrypted vault. Choose **Use release vX** on Deploy, or run `set-release` and
  `upgrade` with no arguments. If you sign releases yourself, pin your key and pass
  `--manifest` as before.
- **A new Fleet web layout.** Grouped navigation, a header with a one-line description,
  and the same tokens as the admin panel.
- **A friendlier launcher.** `scripts/fleet-web.py` switches to Python 3.13 to 3.10
  when your default Python is newer, and explains how to recover from a failed setup.

## Before you upgrade

Check out the `v2.0.1` tag, then open **Upgrade** in Fleet web or run
`cdnfoundry-fleet upgrade --plan-only`. Take a backup first.

## Limits

An automatically signed release proves that your Fleet built it from your checkout. It
does not prove that CI built it. Pin your own key if you need that.
