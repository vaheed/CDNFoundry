# CDNFoundry v2.0.6

v2.0.6 makes Geo-DNS and the Grafana dashboards work on a fresh fleet, keeps domain nameservers honest, and adds a
delete action and registration expiry to the panels. You can upgrade from v2.0.5 with Fleet.

## Fixed

- **Geo-DNS always answered the default.** Production accepts a GeoIP database only when it is verified, but Fleet
  configured no checksum, so every node kept an empty placeholder database. The default provider is now `dbip-npm`,
  which checks the database against the SHA-512 the npm registry publishes for the package, validates it, and
  activates it. PowerDNS reloads the new file within a minute.
- **Most DNS and edge panels in Grafana were empty.** Vector exported the `cdnf` metrics with a leading underscore
  (`_cdnf_dns_queries_total`), so no recording rule matched them. The names are now `cdnf_...`.
- **The PoP logs panel failed for All PoPs.** The selector matched only empty values, which Loki rejects. It now
  carries a non-empty matcher.
- **Edge health probes always failed.** The gateway closed an unrouted plain-HTTP connection without an answer, so
  the HTTP probe read status 0 and the edge availability alerts fired on a healthy PoP. The gateway now answers
  `421`. An unrouted TLS name is still dropped.
- **Our own DNS probe was counted as customer traffic.** The blackbox probe asks for `probe.cdnfoundry.invalid` and
  expects REFUSED, which made up about half of all DNS queries and REFUSED answers in telemetry. Vector now drops that
  name before the metrics and ClickHouse.
- **The red confirm button in light mode failed contrast.** Solid danger buttons use a darker fill.

## Added

- **Delete domain** in the domain page menu. It asks for confirmation, states the removal delay, and uses the same
  policy-aware endpoint as the API.
- **Automatic nameserver checks.** A pending domain is checked by itself on a backoff (1, 2, 5, 10, 15, and 30
  minutes, then hourly for a day, then every six hours) and verifies when the nameservers match. An active domain is
  re-checked every 12 hours and becomes Pending verification after three confirmed changes an hour apart. Its zone and
  edge settings stay, and it is never removed for this. A failed lookup never counts as a change.
- **Registration expiry** in both panels and the API, looked up from the registry (RDAP) about once a week. It turns
  orange inside the warning window (30 days by default) and red at 7 days or fewer. Users are reminded at 30, 14, 7, 1,
  and 0 days.
- A **Domain monitoring** settings group controls the intervals and can switch un-verifying to observe only.

## Before you upgrade

Run **Upgrade** in Fleet web or `cdnfoundry-fleet upgrade --plan-only`. The upgrade runs one expand-only migration.
Nodes download and verify the GeoIP database when the updater restarts, and Fleet sets `MMDB_PROVIDER=dbip-npm`.

Known limits:

- The autonomous-system (ASN) database has no verified default source, so events carry ASN 0 until you set
  `MMDB_ASN_DOWNLOAD_URL` with a checksum.
- Registration expiry shows Unknown for a TLD whose registry publishes no RDAP service.
- `docker-socket-proxy` cuts each container log stream every ten minutes. The log collector reconnects, so logs keep
  flowing, but the `TelemetryDeliveryFailures` warning can fire.
