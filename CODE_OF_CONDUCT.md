# Code of conduct

CDNFoundry contributors must keep project spaces respectful, technical, and
safe. Harassment, discrimination, threats, doxxing, and publication of secrets
or customer data are not acceptable.

Assume good intent while reviewing ideas, but evaluate changes against concrete
product, safety, and operational evidence. Give actionable feedback and keep
disagreement focused on the work.

Report conduct concerns privately to the repository maintainers. Security
vulnerabilities belong in the process described by [SECURITY.md](SECURITY.md),
not in a public conduct report.
